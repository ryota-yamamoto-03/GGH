# 開発ロードマップ(MVP版 → β版 → 正式版)

## 🚀 MVP版(1〜2ヶ月)— まず現場で回す

**目標: 紙のチェック表を置き換え、ポイント制度を回し始める**

- [x] Google ログイン(Supabase Auth)
- [x] ロール管理(利用者 / スタッフ / 管理者)
- [x] ホーム画面(レベル・LP・経験値バー・ステータス表示)
- [x] ライフポイント制度(付与・履歴・レベル計算)
- [x] スタッフの行動チェック → 自動加算
- [x] ポイント行動マスタの管理(管理者が自由に変更)
- [x] デイリー / ウィークリーミッション(自動生成・自動進捗)
- [x] 実績システム(自動解除 + 手動付与)
- [x] ポイント交換所(申請 → スタッフ承認 → お渡し)
- [x] 交換商品の管理(追加・変更・削除)
- [x] ランキング(累計 / 今月 / 年間、ON/OFF・本人非表示設定)
- [x] アプリ内通知(獲得・レベルアップ・交換・お知らせ・イベント)
- [x] 分析画面(週間・月間・達成率・生活リズム・推移)
- [x] 支援記録・コメント・CSV出力
- [x] レスポンシブ / ダークモード
- [x] RLS によるセキュリティ

**MVP運用のゴール**: スタッフ2〜3名・利用者5〜10名で1ヶ月運用し、
ポイント単価・ミッション内容・景品構成のフィードバックを集める。

## 🧪 β版(3〜5ヶ月)— 使い勝手と支援の質を上げる

**目標: 毎日使って楽しい・支援記録として信頼できる状態**

- [ ] レベルアップ演出の強化(全画面エフェクト・効果音・ハプティクス)
- [ ] 実績解除トースト(Steam風ポップアップ)
- [ ] PWA 対応(ホーム画面追加・プッシュ通知)
- [ ] Discord 通知連携(ポイント獲得・イベント告知を GH の Discord へ)
- [ ] LINE 通知連携(LINE Messaging API)
- [ ] 利用者の自己申告 → スタッフ承認フロー(セルフチェック)
- [ ] 支援記録のテンプレート・検索・月次レポート出力(PDF)
- [ ] 分析の強化(曜日別ヒートマップ・服薬/外出の相関・目標設定)
- [ ] イベント参加登録・大会トーナメント表
- [ ] アバター/称号のカスタマイズ(貯めたLPと別の「飾り」要素)
- [ ] 監査ログ(誰がいつポイント・ロールを変更したか)
- [ ] E2E テスト(Playwright)と CI

**β運用のゴール**: 施設全体で常用し、月次の支援会議で分析画面を使えるレベル。

## 🏆 正式版(6ヶ月〜)— 施設の外とつながる

**目標: 家族・医療・福祉ネットワークと連携する支援基盤**

- [ ] 家族向け閲覧画面(本人同意ベースの限定共有リンク)
- [ ] 訪問看護画面(服薬・生活リズムの共有ビュー)
- [ ] 相談支援専門員画面(モニタリング報告向けサマリー)
- [ ] B型作業所との連携(出席データの API 連携 / CSV取込)
- [ ] GPS 外出記録(本人同意前提・プライバシー設定つき)
- [ ] AI による生活リズム分析(乱れの早期検知・声かけ提案)
- [ ] 多施設対応(グループホーム複数拠点・組織アカウント)
- [ ] アクセシビリティ監査(WCAG 2.2 AA)・多言語対応
- [ ] データエクスポート/バックアップの自動化
- [ ] 個人情報保護レビュー(第三者提供同意・保存期間ポリシー)

**正式版のゴール**: 「ゲームで生活が整う」モデルケースとして他施設へ展開できる品質。
